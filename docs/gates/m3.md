## 本批验证

- 三份真实 Main 语料，共 12 帧：64×48 全 I，176×144 I/P（init_idc=1），320×240 双 slice I/P（init_idc=2）。Y/U/V 与 FFmpeg 原始 YUV 逐像素相等。
- 输入 SHA-256 和独立 Oracle YUV SHA-256 已登记到 manifest；九条语料校验通过。包含 B 帧的旧 Main 样本仍明确拒绝。
- `TestCABAC_PCMRestartOracle`：规范固定算术序列选中 I_PCM，验证原始样本及 PCM 后算术引擎重启，并与 FFmpeg 对比。
- `TestCABAC_TruncationRecoversAtIDR`：截断 CABAC slice 返回 `ErrInvalidData`，清除参考状态，后续正确 IDR 恢复解码。
- `cabac/decoder_test.go`：64 个概率状态的 MPS/LPS 转移与翻转点、460 个上下文×52 个 QP×四张初始化表、固定区间 trace、bypass、terminate、截断粘性错误。
- `cabac/residual_test.go`：固定解析残差向量与残差扫描/转义入口 fuzz。
- `go generate ./internal/entropy/cabac`：生成前后 `tables_gen.go` SHA-256 一致，无外部编解码器或网络依赖。
- `go test -count=1 ./...`、`go vet ./...`、`go build ./...`、依赖检查、语料校验、gofmt 与 diff 检查通过；M2 五份真实 Baseline 回归保持通过。
- Windows/Linux/macOS × amd64/arm64 六目标交叉编译通过。这里只证明可编译。

## 后续门禁

第二批已通过：两份多参考 x264 I/P 样本（12+10 帧）及两份 MMCO 定向样本
（type 0/type 1 各 6 帧）与 FFmpeg 逐像素一致；列表排序、帧号回绕、MMCO
1..6、长期索引、池所有权和 POC 周期有独立测试。当前 manifest 共 13 条语料。

第三批已通过：三份默认 Main B-pyramid 样本共 42 帧、16 帧 CAVLC temporal-direct、
12 帧淡出 P 显式权重及 3 帧三平面不同 B 显式权重；全部与 FFmpeg 显示顺序 YUV
逐像素一致。PTS/Duration 在乱序送入后按显示顺序保留；Flush 排空与 Again/EOF、
重复 Flush、输入缓冲复用和 B 去块的参考列表交换匹配均有测试。manifest 共 19 条。

High 批次已通过：七份 High 共 74 帧，含三个默认参数样本、JVT 矩阵、CAVLC、
双 slice。8×8 非 DC 系数与矩阵组合有逐系数解析解，九模式预测有非均匀邻域
向量；实际 High 覆盖率确认执行了 Intra8×8、8×8 残差与矩阵分支。合法隔行
样本明确返回 ErrUnsupported 并在后续 IDR 恢复。全量 race 已通过，常规 CGO=0
门禁通过；当前总计 27 条语料，其中 26 条支持样本 217 帧回归。
