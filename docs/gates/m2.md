## 范围与偏差

- x264 无 B 帧 Baseline 默认使用 POC type 2，因此无重排的 type 2 路径提前在 M2 实现；type 0 有合成 PCM/P、非参考帧与 POC 内核测试。需要重排的输入显式返回 `ErrUnsupported`。
- 只支持完整 Annex-B AU；AVCC/增量流接入在 M6。编码器从 M4 开始。
- CABAC、B、8×8 变换、ScalingMatrix、MMCO、多参考与 POC type 1 尚未实现并显式拒绝。Profile 整体仍为 `Partial`，不把 M2 范围内的验证等同于完整 Baseline 认证。
- 1080p 暂定 30 FPS 尚未达到；M2 退出要求是记录首次实测值，性能与分配优化留在 M8。
- 本地未执行远端 CI 或原生 Linux/arm64/macOS 测试；沿用 M0/M1 约定，保留“本地门禁通过，待 CI”状态。本地 `v0.3.0` 标签在 CI 全绿后再推送。
- 未执行 `-race`：M2 没有内部并行实现，竞态检测在 M8/M9；现有 Makefile 的 CGO=0 与 race 工具链要求仍需在引入并行前处理。
