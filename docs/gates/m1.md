## 3. 已知偏差

| 偏差 | 原因 | 处理 |
|---|---|---|
| CI 尚未首次执行 | 当前开发环境可本地运行 Go 1.27.4，但没有仓库 CI runner | 沿用 M0 惯例：先本地验证并打本地 tag，CI 全绿后再 push tag |
| PPS / VUI / ScalingList / SEI 标 `Partial` | 有真实语料往返，但缺少独立 Oracle；ScalingList 无自定义矩阵语料 | Ledger 已记录；M2/M3 用解码 Oracle 补齐 |
| AVCC/avcC 只有一条真实语料 | 尚无 MP4 demux（明确不在核心范围） | 用 x264 Main MP4 的 avcC 覆盖真实路径 |
| `-race` 与长时 fuzz 未执行 | M8/M9 门禁项；当前无并行实现 | M1 只做短时 fuzz smoke（已执行） |

## 4. 结论

M1 的代码、测试与文档交付完成；本地门禁全部通过。标签 `v0.2.0` 在本地创建，
按 M0 的约定在 CI 首次全绿后再 push。M2 可以从 decoder skeleton 与
CAVLC/Intra 重建开始，直接复用本阶段的 bitstream/nal/syntax。
